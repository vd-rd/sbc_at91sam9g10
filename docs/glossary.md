# Glossary

Shared terms are in the [Glasnost glossary](https://vd-rd.github.io/glasnost.iot/glossary/). Terms specific to this board:

| Term | Meaning |
|---|---|
| **AT91Bootstrap** | Microchip's first-stage bootloader for AT91 processors; on this board it's the `boot.bin` file on the microSD card. |
| **DataFlash** | Atmel/Adesto's SPI flash family (AT45). On this board: 2 MB for data, not bootable. |
| **DBGU** | The processor's debug UART — the hardware behind the debug console. |
| **SAM-BA** | Microchip's recovery mode and PC tool for AT91 processors. |
